# Bravo Agency | Neo-Minimalist Design & Digital

Bravo Agency is a premium, strategic design consultancy tailored for the South African SME market. This repository contains the custom-built, high-performance web presence for the agency.

## 🎨 Brand Philosophy
Bravo operates on a **Neo-Minimalist** aesthetic:
- **Palette:** Electric Cobalt, Linen, and Charcoal.
- **UX:** High-intent interactions, bento-grid layouts, and micro-animations.
- **Strategy:** Value-led service tiers focused on business outcomes over simple deliverables.

## 🛠 Tech Stack
- **Framework:** [React](https://reactjs.org/) (Vite-powered for speed)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Backend/Database:** [Firebase](https://firebase.google.com/) (Lead capture & Contact Form)
- **Compliance:** POPIA-ready (South African Protection of Personal Information Act)

## 🚀 Key Features
- **Bento Expertise Grid:** Interactive expertise cards with hash-link navigation.
- **Dynamic Service Tiers:** Three-tier pricing structure (Identity, Digital, Full Suite).
- **Service Add-on Modals:** Interactive deep-dives into specialized services (Packaging, Pitch Decks, etc.).
- **Responsive Design:** Optimized for mobile-first browsing on SA networks.
- **Lead Management:** Integrated Firebase contact form with professional success states.

## 📂 Project Structure
- `/src/components`: Reusable UI elements (Modals, Buttons, Bento Cards).
- `/src/pages`: Main routing (Home, Services, Privacy, Terms).
- `/public`: High-resolution brand assets and project portfolio.
